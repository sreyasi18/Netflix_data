# Netflix Data Analysis Dashboard

## Project Overview
This project analyzes Netflix content data to identify trends, content distribution, and viewer insights using data analytics and visualization techniques.

## Technologies Used
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- SQL
- Power BI

## Dataset Information
The dataset contains Netflix titles including:
- Show ID
- Title
- Type (Movie / TV Show)
- Director
- Cast
- Country
- Release Year
- Rating
- Duration
- Genre

## Project Workflow
1. Data Collection
2. Data Cleaning and Preprocessing
3. Exploratory Data Analysis (EDA)
4. Data Visualization
5. SQL Analysis
6. Interactive Power BI Dashboard

## Key Analysis Performed
- Distribution of Movies vs TV Shows
- Top Genres on Netflix
- Content Released by Year
- Country-wise Content Distribution
- Rating Analysis
- Duration Analysis

## Dashboard Features
- KPI Cards
- Genre Distribution Charts
- Release Year Trend Analysis
- Country Analysis
- Interactive Filters/Slicers

## Key Insights
- Movies dominate Netflix content compared to TV Shows
- Drama and Comedy are among the most frequent genres
- Content growth increased significantly after 2015
- Some countries contribute more titles than others
